# SQL 学习中心

一个面向中文学习者的 SQL 学习站点，包含教程、速查表、题库、SQLite 在线训练场和学习笔记，帮助大家从零开始掌握 SQL，并在浏览器中直接练习与验证查询。

项目描述：`学习SQL数据库`

## 项目简介

本仓库是一个纯前端的 SQL 学习平台，主要面向以下场景：

- 初学者入门 SQL
- SQL 语法快速查阅
- 真实数据库题目训练
- 在浏览器中直接运行 SQLite
- 记录学习过程中的笔记与易错点

网站包含：

- 完整中文教程
- SQL 速查表
- 150 道练习题
- 浏览器内 SQLite 训练场
- 个人学习笔记

## 主要功能

### 1. 完整教程
- 从基础语法入门
- 覆盖 `SELECT`、条件查询、聚合、连接查询、子查询、窗口函数等
- 每节都有可运行示例

### 2. SQL 速查表
- 汇总常用语法与用法
- 支持快速查阅与一键复制
- 适合在写 SQL 时临时检索

### 3. 题库训练
- 50 道基础入门题
- 100 道进阶实战题
- 支持按难度与类别筛选
- 题目可直接跳转到训练场验证答案

### 4. 在线训练场
- 基于 SQLite（sql.js）
- 无需安装数据库
- 可直接在浏览器中编写 SQL、执行查询、查看结果
- 适合边学边练、边调试

### 5. 学习笔记
- 记录学习心得、常见错误与实践总结
- 支持本地保存与导出
- 可从任意页面快速跳转到笔记页

## 运行方式

由于训练场依赖浏览器中运行 WebAssembly，建议通过本地服务器方式打开项目，而不是直接打开 `file://`。

### 方式 1：Python

```bash
cd learning_sql
python -m http.server 8124
```

然后在浏览器打开：

```text
http://localhost:8124/
```

### 方式 2：移动端/局域网访问

如果你想在同一 Wi‑Fi 下的手机上访问：

```text
http://<你的电脑局域网IP>:8124/
```

> 注意：不要使用 `127.0.0.1` 作为移动端访问地址。
