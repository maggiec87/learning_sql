📌 如何打开（重要）

  • 本站在本地服务器下才能加载训练场引擎（WebAssembly 不允许 file:// 直接运行）。启动命令：python -m http.server 8124（在站点目录下），再访问 http://127.0.0.1:8124/。
  • 📱 手机访问：让手机与电脑连同一 Wi-Fi，用电脑的局域网 IP 打开，例如 http://192.168.x.x:8124/（不要用 127.0.0.1，那是电脑自己）。命令可加 --bind 0.0.0.0 对外放行端口。
  • 示例数据库为「网上书店」：分类 / 作者 / 图书 / 客户 / 订单 / 订单明细 共 6 张表，题库答案均可在该库真实跑通。
